# MFA Global Consultancy

Dinamik kurumsal site + admin panel.

## Stack

- Next.js + Prisma
- Supabase Postgres + Storage
- Hostinger Node.js Web App (canlı)

## Lokal

1. `.env.example` → `.env` (Supabase değerlerini doldur)
2. `npm install`
3. `npm run db:setup`
4. `npm run dev`

- Site: http://localhost:3000
- Admin: http://localhost:3000/admin  
  `admin@mfaglobalconsultancy.com` / `admin123`
